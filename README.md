# radiocert — built site

**<https://mjbommar.github.io/radiocert/>**

Self-study courseware for the FCC amateur radio licences and the FAA remote
pilot certificate. Lessons, practice questions, figures, and a knowledge graph,
all derived from the published question pools and the regulations themselves.

Free to use. Nothing about your study history leaves your browser — progress is
kept in `localStorage`, there is no account, no analytics, and no server to send
it to. There is an export/import button so you can move it between devices
yourself.

## This repository is generated

Every file here is build output, force-pushed by CI from the private source
repository each time it changes. Edits made here are destroyed by the next
build. Issues and corrections are welcome — open one here and it will be fixed
at the source.
